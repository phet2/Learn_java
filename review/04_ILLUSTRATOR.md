# ບົດຮຽນ Adobe Illustrator 2025 (Windows)

> ໜ້າຈໍ ແລະ ໄອຄອນໃນບົດຮຽນນີ້ເປັນ **ໜ້າຈໍຈຳລອງ** ທີ່ວາດໃໝ່ໃຫ້ຄ້າຍກັບໂປຣແກຣມຈິງ — ຕຳແໜ່ງ ແລະ ຊື່ເຄື່ອງມືອີງຕາມ Illustrator 2025 ແຕ່ຮູບໄອຄອນອາດຕ່າງຈາກຂອງຈິງເລັກນ້ອຍ ຖ້າມີໂປຣແກຣມ ໃຫ້ເປີດທຽບໄປພ້ອມ. ຄີລັດເປັນແບບ **Windows** (Mac ປ່ຽນ Ctrl → Cmd, Alt → Option).
>
> 📝 ຮຽນແລ້ວ ລອງທຳ **[ຂໍ້ສອບລອງທຳ Illustrator](/ai-exam/)** — ປາລະໄນ 48 ຂໍ້, ທາຍໄອຄອນ 10 ຂໍ້, ອັດຕະໄນ 10 ຂໍ້

## 1. ພາບລວມໜ້າຈໍ (Workspace)

ເມື່ອເປີດ ຫຼື ສ້າງໄຟລ໌ໃໝ່ Illustrator ຈະສະແດງໜ້າຈໍແບບ **Essentials** (ຄ່າເລີ່ມຕົ້ນ). ໜ້າຈໍແບ່ງເປັນ 8 ສ່ວນຫຼັກ — ແຕະໝາຍເລກເພື່ອເບິ່ງແຕ່ລະສ່ວນ:

<!-- include:ai-workspace -->

**ຄວນຮູ້ເພີ່ມ**
- **Workspace** = ການຈັດວາງ panel ທັງໝົດ · ປ່ຽນ ຫຼື ຄືນຄ່າເດີມທີ່ `Window > Workspace > Essentials` ແລະ `Reset Essentials`
- **Control Panel** (ແຖບຕົວເລືອກແນວນອນໃຕ້ເມນູ) ບໍ່ສະແດງໃນ Essentials ແລ້ວ — ເປີດໄດ້ທີ່ `Window > Control`
- ກົດ `Tab` = ເຊື່ອງ/ສະແດງ panel ແລະ toolbar ທັງໝົດ · `Shift+Tab` = ເຊື່ອງສະເພາະ panel ທາງຂວາ
- ໜ້າ **Home** ຈະສະແດງຕອນເປີດໂປຣແກຣມ ກ່ອນເປີດໄຟລ໌

## 2. ແຖບເຄື່ອງມື (Toolbar)

Toolbar ມີ 2 ແບບ:
- **Basic** — ຄ່າເລີ່ມຕົ້ນ ສະແດງແຕ່ເຄື່ອງມືທີ່ໃຊ້ເລື້ອຍ
- **Advanced** — ສະແດງເຄື່ອງມືຄົບ · ເປີດທີ່ `Window > Toolbars > Advanced` (ບົດຮຽນນີ້ໃຊ້ແບບ Advanced)

**ກົດທີ່ຄວນຈື່:**
- ໄອຄອນທີ່ມີ **ສາມຫຼ່ຽມນ້ອຍຢູ່ມຸມ** = ມີເຄື່ອງມືຊ່ອນຢູ່ໃນກຸ່ມ → **ກົດຄ້າງ** ຫຼື **ຄລິກຂວາ** ເພື່ອເປີດ
- **Alt + ຄລິກ** ໄອຄອນ = ສະຫຼັບໄປເຄື່ອງມືຖັດໄປໃນກຸ່ມ
- **ດັບເບີ້ນຄລິກ** ໄອຄອນ = ເປີດໜ້າຕ່າງຕັ້ງຄ່າຂອງເຄື່ອງມືນັ້ນ (ໃຊ້ໄດ້ກັບຫຼາຍເຄື່ອງມື ເຊັ່ນ Rotate, Scale, Blend)
- ສີທີ່ຂອບປຸ່ມຂ້າງລຸ່ມ = ກຸ່ມຂອງເຄື່ອງມື (ເຮັດໃຫ້ຈື່ງ່າຍ — ໂປຣແກຣມຈິງບໍ່ມີສີນີ້)

## 3. Panels ທີ່ສຳຄັນ

Panel ຄືແຜງຄວບຄຸມທາງຂວາຂອງໜ້າຈໍ · ເປີດທຸກ panel ໄດ້ທີ່ເມນູ **Window** · panel ທີ່ໃຊ້ເລື້ອຍທີ່ສຸດໃນ 2025 ຄື **Properties** ເຊິ່ງປ່ຽນເນື້ອໃນຕາມວັດຖຸທີ່ເລືອກ.

### 3.1 Layers — ຈັດການຊັ້ນ

Layer ຄືແຜ່ນໃສທີ່ຊ້ອນກັນ — ວັດຖຸໃນ Layer ເທິງຈະບັງ Layer ລຸ່ມ. ໃຊ້ແຍກສ່ວນງານ (ເຊັ່ນ ພື້ນຫຼັງ / ຮູບ / ຕົວອັກສອນ) ເພື່ອແກ້ໄຂງ່າຍ.

<!-- include:ai-panel:layers -->

### 3.2 Swatches ແລະ Color — ສີ

**Swatches** ເກັບສີທີ່ໃຊ້ເລື້ອຍ · **Color panel (F6)** ປັບສີດ້ວຍຕົວເລກ RGB / CMYK / HSB · **Color Guide** ແນະນຳຊຸດສີທີ່ເຂົ້າກັນ.

### 3.5 Pathfinder — ລວມ ແລະ ຕັດຮູບຮ່າງ

Pathfinder ມັກອອກສອບ! ແຖວເທິງ **Shape Modes** (4 ປຸ່ມ) ແລະ ແຖວລຸ່ມ **Pathfinders** (6 ປຸ່ມ). ຕ້ອງເລືອກວັດຖຸ 2 ອັນຂຶ້ນໄປກ່ອນ.

**Character (Ctrl+T)** ຈັດຮູບແບບຕົວອັກສອນ · **Paragraph (Alt+Ctrl+T)** ຈັດຫຍໍ້ໜ້າ: ຊິດຊ້າຍ, ກາງ, ຂວາ, ເຕັມແຖວ (Justify), ຍະຫວ່າງກ່ອນ/ຫຼັງຫຍໍ້ໜ້າ.

## 6. ທິດສະດີພື້ນຖານ

### 6.1 Vector ແລະ Raster

<!-- include:ai-vector-raster -->

| ຫົວຂໍ້ | Vector | Raster (Bitmap) |
|---|---|---|
| ເກັບຂໍ້ມູນເປັນ | ເສັ້ນ ແລະ ຮູບຮ່າງ (ສູດຄະນິດສາດ) | ຈຸດສີ (Pixel) |
| ຂະຫຍາຍແລ້ວ | ບໍ່ແຕກ ຄົມຊັດສະເໝີ | ແຕກ ເປັນຕາລາງ |
| ຂະໜາດໄຟລ໌ | ນ້ອຍ | ໃຫຍ່ຕາມຄວາມລະອຽດ |
| ເໝາະກັບ | ໂລໂກ້, ໄອຄອນ, ຕົວອັກສອນ, ປ້າຍໃຫຍ່ | ຮູບຖ່າຍ, ຮູບທີ່ມີລາຍລະອຽດແສງເງົາສູງ |
| ໂປຣແກຣມ | Illustrator, CorelDRAW, Inkscape | Photoshop, GIMP |
| ນາມສະກຸນ | AI, EPS, SVG, PDF | JPG, PNG, GIF, PSD |

### 6.2 RGB ແລະ CMYK

<!-- include:ai-color-modes -->

- **Spot Color** (ເຊັ່ນ **Pantone**) = ໝຶກສີສຳເລັດຮູບ ໃຊ້ໃນງານພິມທີ່ຕ້ອງການສີແບຣນໃຫ້ຖືກຕ້ອງ ແນ່ນອນ
- **Process Color** = ສີທີ່ເກີດຈາກການຜະສົມໝຶກ C, M, Y, K
- ສີບາງສີໃນ RGB ພິມອອກ CMYK ບໍ່ໄດ້ (ເຊັ່ນ ສີນີອອນ) — ສະນັ້ນງານພິມຕ້ອງເລີ່ມດ້ວຍ CMYK

### 6.3 ສ່ວນປະກອບຂອງ Path

<!-- include:ai-path-parts -->

- **Corner Point** (ຈຸດມຸມ) = ເສັ້ນຫັກມຸມ · **Smooth Point** (ຈຸດໂຄ້ງ) = ມີ handle 2 ຂ້າງ ເສັ້ນໂຄ້ງຕໍ່ເນື່ອງ
- **Compound Path** (`Ctrl+8`) = ລວມຫຼາຍ path ເປັນອັນດຽວ ພື້ນທີ່ທີ່ຊ້ອນກັນຈະເປັນຮູ (ເຊັ່ນ ຮູໃນຕົວ O)
- **Clipping Mask** (`Ctrl+7`) = ໃຊ້ຮູບຮ່າງເທິງສຸດເປັນກອບ ເຊື່ອງສ່ວນທີ່ຢູ່ນອກກອບ (ເຊັ່ນ ໃສ່ຮູບຖ່າຍໃນວົງມົນ)

## 7. ຝຶກຕອບ: ເຄື່ອງມືນີ້ຄືຫຍັງ?

ກົດ **ຝຶກຕອບ** ດ້ານເທິງເພື່ອເຊື່ອງຊື່ເຄື່ອງມື → ເບິ່ງໄອຄອນແລ້ວຕອບໃນໃຈວ່າ **ຊື່ຫຍັງ ຄີລັດຫຍັງ ໃຊ້ເຮັດຫຍັງ** → ແຕະເພື່ອເບິ່ງຄຳຕອບ.
